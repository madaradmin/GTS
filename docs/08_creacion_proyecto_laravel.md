### 2. COMANDOS CLAVE DE GESTIÓN

* **Verificar estado general:** `php artisan about`
* **Ejecutar servidor de desarrollo local:** `php artisan serve`
* **Consola interactiva de depuración:** `php artisan tinker`
* **Listado de rutas disponibles:** `php artisan route:list`
